## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Premium Dark Theme** | Deep navy/purple neon aesthetic with glassmorphism UI |
| 🌌 **3D Particle Background** | Interactive Three.js particle system with dynamic connections |
| 🎭 **Smooth Animations** | Page-wide Framer Motion animations & micro-interactions |
| 📱 **Fully Responsive** | Pixel-perfect on all devices — mobile, tablet, desktop |
| ✉️ **Working Contact Form** | Integrated with Web3Forms — messages sent directly to email |
| 📄 **Downloadable CV** | One-click resume download from the hero section |
| 🧭 **Smart Navbar** | Glassmorphism header with scroll detection, active section tracking & animated underline |
| ⚡ **Fast Performance** | Vite-powered build with optimized assets |

## 🖥️ Sections

- **Hero** — Animated intro with typing effect, stats counter & particle background
- **About** — Personal info, highlights, and quick facts
- **Skills** — Interactive Research Matrix Terminal with cyber-styled skill clusters, dynamic typing effects, and segmented data visualizers
- **Projects** — Holographic Blueprint grid showcasing live projects with laser-scanning animations, tech-node system & 10K+ users served
- **Experience** — Professional timeline with role details

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/MathuR-A01/aayu-port.git

# Navigate to the project
cd aayu-port

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be running at `http://localhost:5173`

### Build for Production

```bash
npm run build
```
